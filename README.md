# K Ganesh Reddy — Student Portfolio

A responsive student portfolio built with plain HTML, CSS and JavaScript.

## Folder structure

```text
K_Ganesh_Reddy_Portfolio/
├── index.html
├── style.css
├── script.js
├── resume.html
├── README.md
└── assets/
```

## Run in VS Code

1. Extract the ZIP file.
2. Open VS Code.
3. Select **File → Open Folder** and choose `K_Ganesh_Reddy_Portfolio`.
4. Install the **Live Server** extension if it is not already installed.
5. Right-click `index.html` and choose **Open with Live Server**.
6. Your browser will open the portfolio locally.

You can also open `index.html` directly in a browser, but Live Server is recommended while editing.

## Publish using GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `ganeshreddy47.github.io` or `ganesh-portfolio`.
2. Upload the contents of this extracted folder to the repository root. Make sure `index.html` is at the root, not inside another nested folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The Pages section will show your public website URL.

## Before publishing

- Confirm that Python, Java, SQL and Excel are skills you can confidently discuss. They are marked for verification in the portfolio.
- Confirm whether the listed courses/certifications are yours and completed. They are not claimed as completed on the website.
- Add your actual LinkedIn URL if you want it displayed.
- Add project GitHub links, photos, implementation details and testing results when ready.
- Replace the resume placeholder content with verified details. Open `resume.html` and use **Print / Save as PDF** to create a PDF copy.
- Check that you are comfortable making the email address and GitHub profile public.

## Customisation

- Edit page content in `index.html`.
- Change colours, spacing and layout in `style.css`.
- Change navigation and scroll interactions in `script.js`.
- Update the resume in `resume.html`.

The Google Fonts import requires an internet connection. The site layout and functionality otherwise use no frameworks or build tools.
